适用于 Zotero Connector 的非官方助手 · @@VERSION@@

PDF 和当前网页，一次保存

这份安装包已经构建好。你只需要在 Chrome 中选中插件文件夹，之后照常保存论文。

1先把 ZIP 完整解压

把压缩包解压到一个准备长期保留的位置，然后从解压后的文件夹打开本页面。不要在压缩包预览窗口里安装。

📁 extension ← Chrome 里要选择的文件夹

这个文件夹里面应当能看到 manifest.json。安装后保留整个文件夹，不要删除或移动。

2在 Chrome 中加载一次

复制下面的地址，在 Chrome 地址栏粘贴并回车：

chrome://extensions

打开右上角开发者模式 → 点击加载已解压的扩展程序 → 选择上面的 extension 文件夹。

解压后的 extension 文件夹

如果已经装过其他 Zotero Connector，保留安装，只停用旧版本；同一时间只启用一份。这个包不需要双击运行 EXE 或执行命令。

3回到 Chrome，点击扩展保存

  • 保持 Zotero 桌面端打开。
  • 回到 Chrome 的论文网页，点击 Chrome 工具栏中的“Zotero 双存助手”图标，在弹窗中选择文库或分类。

扩展可固定到 Chrome 工具栏，方便之后使用。

保存后展开文献条目，核对 PDF 和 “网页快照 · 论文题名” 两个附件。

首次使用时，Zotero 中需启用“保存条目时自动附加相关 PDF”和“从网页创建条目时自动抓取网页快照”。插件不负责获取未加载的全文或突破访问限制。

遇到问题，先看这四条

  • 提示清单文件缺失：选错层级了。应选择含有 manifest.json 的 extension 文件夹。
  • 点击没有反应：确认只启用一份 Connector。首次安装或更新后刷新论文页。
  • 只有 PDF：确认是在论文网页保存，并检查 Zotero 的自动网页快照设置。直接在 PDF 阅读器保存时，不额外添加论文网页。
  • 更新：关闭 Chrome 后，用新包的 extension 内容替换原安装文件夹里的内容；重新打开后在扩展页点重新加载，再刷新论文。保留原路径更方便。
