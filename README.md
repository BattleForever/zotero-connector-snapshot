# 译存 YiCun

保存论文时，同时归档浏览器中已经显示的译文网页。

基于 Zotero Connector 的非官方修改；当前仅支持 **Chrome Connector 5.0.217**。
先完成沉浸式翻译，再点击扩展，继续使用原版保存弹窗选择文库和分类。
PDF 沿用原来的下载流程，译文快照附在同一个文献条目下。

## 名称与文件名

| 对象 | 规则 |
| --- | --- |
| 扩展 | 译存 · 论文与译文快照 |
| 论文题录 | 保留出版信息中的原题名，供检索与引用 |
| 网页快照附件 | 译文快照 · 论文题名（题名最多 120 个 Unicode 字符） |
| PDF 文件 | 第一作者 - 年份 - 论文题名.pdf（通过 Zotero 原生命名模板） |

PDF 文件名由 Zotero 桌面端决定，浏览器插件不直接改动磁盘文件。
设置方法和示例见 [命名规则](docs/NAMING.md)。既有文献不会被批量改名。

## 构建和安装

仓库只包含可审阅的修改源码和构建工具，不附带上游打包库或个人论文。
需要 Python 3.10+；构建本身不下载依赖、不访问网络、不写入文献库。

1. 准备官方 **5.0.217** Chrome Connector 的完整解压目录。只支持锁定版本；
   不要使用本项目的修改版作为输入，不要在 Chrome 运行时改动商店安装文件。
2. 在本仓库目录运行，替换示例中的路径：

```powershell
python tools/build.py --base "PATH_TO_OFFICIAL_5.0.217" --output build/extension
```

3. 在 Chrome 扩展管理页保留但停用原版，启用开发者模式，加载 `build/extension`。
4. 固定“译存”到工具栏，刷新论文页，重新完成翻译并保存。只启用一份 Connector。

输入文件逐一核对 `baseline.lock.json`；版本或内容不符时直接停止，不会猜测适配。
输出目录必须不存在，构建不会覆盖已加载插件或官方文件。
官方升级后需要重新适配，本项目当前不提供自动升级。

## 保存行为

- 快照取自当前已加载的页面 DOM；不会根据题录 URL 重新抓取正文。
- 至少检测到 40 个可见译文字符、200 个页面文本字符；译文稳定 1 秒后捕获，最多等待 12 秒。
- 校验译文样本和无脚本的离线显示；未通过的快照不发送给 Zotero，PDF 流程继续。
- 翻译完成后再次点击同一保存会话，可重试失败的快照，避免重复题录和 PDF。
- 保留原版保存弹窗、文库/分类选择、标签及在线保存回退。

## 已知边界

当前新增流程针对单篇论文的 HTML 页面；不为 PDF 阅读器或多篇搜索结果追加译文网页。
Zotero 桌面端应保持开启，并启用自动网页快照。在线回退保留，但译文快照的在线保存尚未实测。
仅保存当前已加载并翻译的内容，不负责翻译、自动滚动或加载剩余全文。
跨域 iframe、特殊阅读器和翻译插件 DOM 变化仍可能导致拒绝保存。
已验证的空白或隐藏反例会被拦截，不代表适用于所有网站。
