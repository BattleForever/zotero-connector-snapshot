# 命名规则

扩展显示名称为“译存 · 论文与译文快照”，短名称为“译存”。
发布版本为 `0.2.0-rc.1`；Chrome 数字版本为 `5.0.217.3`，兼容基线为 Connector `5.0.217`。

论文题录保留原始题名。网页附件显示为“译文快照 · 论文题名”。
仅为附件标签去除常见排版标签、控制字符和多余空白；不会改写父条目。
过长标签保留 119 个 Unicode 字符加省略号，空题名回退为“译文快照”。
保存失败时显示“译文快照未保存”，具体原因继续显示在原保存进度和通知中。

PDF 的磁盘名称与附件列表中的标题是两回事。Connector 的桌面保存接口并没有
可强制指定最终 PDF 文件名的字段，最终应使用 Zotero 自身的命名功能。
在桌面端“设置 → 常规 → 文件重命名 → 自定义文件名格式”粘贴以下模板：

```text
{{ authors max="1" name="family" suffix=" - " }}{{ year suffix=" - " }}{{ title truncate="120" }}
```

示例：`Li - 2026 - Acoustic sensor for temperature monitoring.pdf`。
作者使用第一作者姓氏；年份或作者缺失时不生成对应分隔符；题名最多 120 字符。
非法文件名字符、同名冲突和最终路径由 Zotero 自身处理。
如使用其他附件移动/重命名插件，应让其沿用 Zotero 文件名，或设置相同模板。
仓库提供模板文件 `config/zotero-filename-template.txt`，构建不会更改桌面设置。

模板用于后续保存；本项目不会批量改动已有附件。附加材料仍遵循 Zotero 自身的
命名规则，避免把多个不同附件都强制命名为同一个论文标题。

官方说明：https://www.zotero.org/support/file_renaming
