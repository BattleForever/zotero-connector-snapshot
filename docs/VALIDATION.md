# 验证范围

`tests/naming.cjs` 检查附件标签中的中英文题名、控制字符、长文本和非 BMP 字符，
并在实际 ItemSaver 保存调用边界检查新名称、重试恢复和父条目保持。
`tests/build_checks.py` 构建两次并比较逐文件摘要，验证基线未改动、权限未扩大、
原版目录 UI 保持一致、在线回退和子 frame 防重复注入。
构建测试同时确认版本不符会失败，输出目录存在时拒绝覆盖，外加文件不会被复制。
测试使用合成内容，RPC 被替换为记录桩；不是实时浏览器或真实文库端到端验收。

先前版本已在真实论文页面确认原版目录选择、PDF 和译文快照同父条目，以及离线可见译文。
该次验收不能替代当前命名候选版的用户验收；此候选版须重载后检查实际名称及 PDF 文件名。
先前全量浏览器夹具曾发生加载超时，不将其记为通过，也不声称全网站兼容。

发布前人工检查：

可先运行 `python tools/serve_fixture.py` 并打开其输出的本机合成页面。
该页面只有在明确点击保存按钮后才会创建标题带 TEST 的真实 Zotero 条目；
启动诊断不创建条目。验收完成后按 Ctrl+C 关闭测试服务。

1. 重载候选版并刷新论文页，确认扩展名称、原保存弹窗和分类选择正常。
2. 完成翻译后保存，确认 PDF 和“译文快照 · 题名”属于同一条目。
3. 独立打开 HTML，确认所需译文可见；核对新 PDF 的实际磁盘名称。
4. 检查快照失败重试不新增父条目，附加 PDF 和原有设置仍正常。
5. 阅读许可与源码范围后，再由维护者最终批准公开推送。
