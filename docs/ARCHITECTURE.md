# 实现与构建

`src/page_snapshot.js` 提供附件标签、当前页面检查、离线非空检查和捕获元数据。
不依赖沉浸式翻译选择器、语言识别、译文字数或译文样本。
`tools/patch_connector.py` 将其加入 ItemSaver，复用原版 SingleFile、保存会话及父条目。
捕获保留当前页面样式配置，支持原文和已经插入的译文。

原版分类选择、PDF 下载和在线回退继续使用原逻辑。
所有已初始化 frame 响应 ping，避免重复注入。
同会话失败快照可重试，不重复创建题录或 PDF。

`tools/build.py` 仅复制锁定基线，在独立工作目录应用补丁并检查权限与资源。
构建不联网、不修改输入、不读取文库或浏览器配置；失败目录保留以供诊断。
启动诊断只读取本机状态，页面诊断仅在指定本机合成验收页显示。
PDF 命名使用桌面端原生模板，涵盖 Connector 下载和 Zotero 自己找到的 PDF。
